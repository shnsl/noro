# NEURO

Nörolojik rehabilitasyon için hasta değerlendirme ve 30 dakikalık seans planı uygulaması (Vite + React + TypeScript + PWA).

## Kurulum

```bash
npm install
cp .env.example .env
```

`.env` dosyasına Firebase web config değerlerini yaz. Sonra:

```bash
npm run dev
```

Firebase proje kimliği için `.firebaserc.example` dosyasını `.firebaserc` olarak kopyalayıp doldur.
